# A301 Swerve Module CAD

![A301 swerve module](<Screenshot 2026-07-21 220702.png>)

This folder contains CAD files for an A301-based swerve module used for Systemcore, Motioncore, and A301 testing.

## Files

- `V1 A301 Swerve Module.f3z` - Fusion 360 archive
- `V1 A301 Swerve Module.step` - STEP export
- `Screenshot 2026-07-21 220702.png` - reference image

## Module Notes

- Uses two A301 motors: one for wheel drive and one for steering.
- Uses goBILDA structure for the module frame.
- Uses an Axon bevel gear for the drive output.
- Uses a pulley system for steering.

## Pulley Versions

V1:

- 16-tooth pulley on the motor
- 36-tooth pulley on the module
- Metal motor pulley and 3D-printed module pulley

V2:

- 36-tooth pulley on the motor
- 36-tooth pulley on the module
- Both pulleys are 3D printed
