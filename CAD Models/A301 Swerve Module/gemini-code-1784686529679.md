# A301 Swerve Module Prototype

![A301 Swerve Module Assembly](Screenshot 2026-07-21 220702.jpg)

## Overview
This folder contains the documentation and Fusion 360 assembly files for the custom swerve module prototype. Originally conceptualized for FRC, this module is currently being utilized for new system core testing for FTC and Alpha. 

As noted by Yoav, this assembly is designed entirely around the new **FIRST A301 Prototype motors**.

## Construction & Mechanics
The module is built to provide independent drive and steering (pivot) control, constructed with the following key components and mechanisms:

*   **Structural Hardware:** The module's framework and structural foundation rely predominantly on goBILDA components.
*   **Drive Transmission:** An Axon bevel gear is utilized to efficiently transfer rotation from the A301 drive motor downward to the wheel axle.
*   **Pivot Mechanism:** The module's steering rotation (pivoting the entire wheel assembly) is driven by a pulley system connected to the secondary A301 motor.

## Version Iterations
There are two distinct versions of the pivot pulley system depending on your specific testing and build needs:

### Version 1 (V1)
*   **Pulley Ratio:** 16-tooth (motor) to 36-tooth (module).
*   **Materials:** Features one metal pulley (mounted to the motor) and one 3D-printed pulley.

### Version 2 (V2)
*   **Pulley Ratio:** 36-tooth to 36-tooth (1:1 ratio).
*   **Materials:** Features an entirely 3D-printed pulley setup. Both the motor-mounted pulley and the secondary pulley are 3D printed, completely replacing the metal component from V1.
