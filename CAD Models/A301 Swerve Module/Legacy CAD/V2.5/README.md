# A301 Swerve Module CAD (V2.5)

V2.5 is an archived release preserved as part of the module's design history. Current CAD uploads moved to Google Drive.

## V2.5 Design Summary

| Area | Detail |
| --- | --- |
| Drive motor | A301 |
| Steering motor | A301 |
| Structure | goBILDA |
| Drive output | Fully geared transmission |
| Steering output | Direct drive via bolted center shaft |
| Drive path | 62T to 80T, attached 20T to 20T, then 2.8:1 Axon bevel |
