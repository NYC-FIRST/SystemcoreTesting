# A301 Mecanum Chassis Legacy CAD

This folder records the older mecanum CAD that was previously managed through this repository.

| Version | Archive contents | Status |
| --- | --- | --- |
| [`V1`](V1/) | Repository CAD status record | Legacy |

## V1 Compared with the Current Design

| Version | Manufacturing approach | Tolerance approach |
| --- | --- | --- |
| V1 | Rapid prototype made from laser-cut wood | Hole tolerances were not a major focus because the goal was to build and test the chassis quickly |
| Current | CNC-machined chassis | Several holes use revised tolerances to account for CNC machining and improve component fit |

V1 was mainly used to prove the mecanum layout as quickly as possible. The current design keeps the same overall idea but is prepared more carefully for metal CNC manufacturing.
