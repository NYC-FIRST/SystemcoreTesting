Coordinate and Control Convention
=================================

Left stick X:
  Raw left-stick X is used in the final example.
  The drivetrain math handles the sign needed for this robot layout.

Left stick Y:
  Y is negated in code because pushing the joystick forward commonly reports
  a negative value.

Right stick X:
  Rotation is kept as raw right-stick X.


Final Example Motor Mapping
===========================

frontLeftPower  -> robot.motor3 -> Hub port 3 -> front-left wheel
frontRightPower -> robot.motor1 -> Hub port 1 -> front-right wheel
backPower       -> robot.motor2 -> Hub port 2 -> back wheel
unused          -> robot.motor0 -> Hub port 0


Final Example Math
==================

x        = leftStickX
y        = -leftStickY
rotation = rightStickX

frontLeftPower  =  0.5 * x + 0.866 * y + rotation
frontRightPower =  0.5 * x - 0.866 * y + rotation
backPower       = -1.0 * x             + rotation

maxMagnitude = max(1.0, abs(frontLeftPower), abs(frontRightPower), abs(backPower))

motor3Throttle = speedScale * frontLeftPower  / maxMagnitude
motor1Throttle = speedScale * frontRightPower / maxMagnitude
motor2Throttle = speedScale * backPower       / maxMagnitude
motor0Throttle = 0.0
