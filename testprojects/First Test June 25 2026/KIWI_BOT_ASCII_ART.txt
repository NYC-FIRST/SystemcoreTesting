Power Mapping
=============

frontLeftPower   -> motor3 / port 3
frontRightPower  -> motor1 / port 1
backPower        -> motor2 / port 2


Final Teaching Math
===================

x        = leftStickX
y        = -leftStickY
rotation = rightStickX

frontLeftPower   =  0.5 * x + 0.866 * y + rotation
frontRightPower  =  0.5 * x - 0.866 * y + rotation
backPower        = -1.0 * x             + rotation

maxMagnitude = max(1.0, abs(frontLeftPower), abs(frontRightPower), abs(backPower))

motor3Throttle = speedScale * frontLeftPower  / maxMagnitude
motor1Throttle = speedScale * frontRightPower / maxMagnitude
motor2Throttle = speedScale * backPower       / maxMagnitude
motor0Throttle = 0.0


Notes
=====

This is intentionally cleaner than a direct image-to-ASCII conversion. Direct conversion
captures the CAD shading and screws, but it makes the wheel geometry harder to teach.
This version keeps the important idea: two front Kiwi wheels, one back Kiwi wheel, and
the actual Expansion Hub ports used in code.
